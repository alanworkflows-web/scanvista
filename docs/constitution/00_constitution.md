# ScanVista Constitution

*This document is the highest authority in the ScanVista project. It supersedes all feature requests, design iterations, and technological trends. It defines why we exist.*

## Core Purpose
ScanVista exists to help hospitality professionals make better decisions.

## Absolute Truths
1. **The OS never replaces hospitality.** It enables it.
2. **The OS never replaces empathy.** It provides the time for it.
3. **The OS prepares.** People care.
4. **Managers decide.** The system advises, coordinates, and learns, but the human always holds the final authority.
5. **Knowledge belongs to the property.** When a manager leaves, their accumulated wisdom must remain.
6. **The OS must make every property wiser every day.**

*All future architecture, code, and design must derive from these truths. If a feature conflicts with this Constitution, the feature must be rejected.*
