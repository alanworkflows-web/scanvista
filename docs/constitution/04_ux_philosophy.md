# UX Philosophy

*These design rules ensure that ScanVista remains a premium, cohesive, and stress-reducing operating system.*

## Design Rules
1. **Two-color palette.** Restrain color usage. Rely on a primary brand color and a secondary accent.
2. **Calm before colorful.** The interface should feel serene by default. Color is reserved for meaning (status, urgency, or primary actions), not decoration.
3. **Information density without clutter.** A manager needs to see the whole picture at a glance. Use structured grids and tight typography, but maintain clear boundaries.
4. **One primary action per screen.** Never confuse the user about what they are supposed to do next.
5. **Progressive disclosure.** Show the summary first. Hide the complex evidence, history, or deep configuration behind a "drill down" or expansion interaction.
6. **Never overwhelm.** If a page requires scrolling through dozens of disconnected widgets, the information architecture has failed.
7. **Luxury over novelty.** The interface should feel like a premium tool, not a trendy social app.
8. **Minimal animations.** Use micro-animations strictly to guide the eye or confirm an action. Do not use decorative, long-duration transitions.
9. **Calm confidence.** The UI language should be direct, professional, and assured.
10. **White space has value.** Let elements breathe. Negative space is a tool to group related information naturally without drawing heavy borders.
11. **Status colors mean the same thing everywhere.** Emerald is Ready/Success, Amber is Warning/Attention, Red is Critical/Blocked. Do not deviate.
12. **Typography carries hierarchy, not decoration.** Use font weights, sizes, and specific font families (e.g., serif for headers, sans for data) to communicate structure instantly.
13. **Decision Density.** Every screen or widget must answer: "What decision will the user make after reading this?" If the answer is "none," remove the widget. Avoid vanity metrics.
